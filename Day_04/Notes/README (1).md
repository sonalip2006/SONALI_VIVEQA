# Day 04: Basic Flip-Flop Implementations## OverviewThis directory contains the Verilog HDL source code and corresponding testbenches for the four fundamental sequential logic memory elements: D, T, JK, and SR Flip-Flops.## Project Files### D (Data) Flip-Flop* **`d\\\\\\\_flipflop.v`**: The core Verilog module implementing the D Flip-Flop behavior.* **`tb\\\\\\\_d\\\\\\\_flipflop.v`**: The simulation testbench used to verify the D Flip-Flop logic.### T (Toggle) Flip-Flop* **`t\\\\\\\_flipflop.v`**: The core Verilog module implementing the T Flip-Flop behavior.* **`tb\\\\\\\_t\\\\\\\_flipflop.v`**: The simulation testbench used to verify the T Flip-Flop logic.### JK Flip-Flop* **`jk\\\\\\\_flipflop.v`**: The core Verilog module implementing the JK Flip-Flop behavior.* **`tb\\\\\\\_jk\\\\\\\_flipflop.v`**: The simulation testbench used to verify the JK Flip-Flop logic.### SR (Set-Reset) Flip-Flop* **`sr\\\\\\\_flipflop.v`**: The core Verilog module implementing the SR Flip-Flop behavior.* **`tb\\\\\\\_sr\\\\\\\_flipflop.v`**: The simulation testbench used to verify the SR Flip-Flop logic.
